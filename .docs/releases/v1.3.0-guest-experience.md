## Release Summary

Sprint 4 melengkapi pengalaman **tamu undangan**: pemilik kini dapat mengelola daftar tamu (tambah, ubah status RSVP, statistik) dan menyediakan **amplop digital** berupa info transfer pada undangan — sementara halaman publik menampilkan rekening aktif dengan tombol salin. Sprint ini juga **menutup seluruh temuan audit Sprint 3**: verifikasi E2E penuh terhadap PostgreSQL asli (21/21 PASS) dan 5 perbaikan LOW (validasi hex tema, token overlay, rate limiting, util bersama, dokumentasi JWT secret).

Release ini adalah **The Guest Experience Release** — Fase 2 (Core Features) resmi selesai; platform undangan digital BERNADA.ID kini berfungsi ujung-ke-ujung.

## Highlights

- **PostgreSQL terpasang & diverifikasi** — PostgreSQL 18.4 (scoop); `npm run db:create` + `npm run migrate` 0001–0004 sukses (8 tabel).
- **Verifikasi E2E 21/21 PASS** — register → login → CRUD invitation → publish → guestbook → guests → gift-accounts → refresh → logout; rekam di `.docs/e2e/sprint-4-verification.md` (menutup temuan **MEDIUM AC7**).
- **Manajemen tamu** — migrasi `0004` (tabel `guests`), service `guest-service.js` (owner-scoped, statistik agregat), API `GET/POST /api/invitations/:id/guests`, `GET .../guests/stats`, `GET/PATCH/DELETE /api/guests/:guestId`; validasi status + batch maks 500.
- **Amplop digital** — migrasi `0004` (tabel `gift_accounts`), API owner CRUD + publik `GET /api/invitations/public/:slug/gift-accounts` (hanya aktif).
- **Builder UI "Kelola"** — statistik tamu, tambah tunggal/bulk, filter status, kelola rekening amplop (tambah/toggle aktif/hapus).
- **Halaman publik** — section Amplop Digital + tombol salin nomor rekening (fallback saat API tidak tersedia).
- **Health check di repo** — `scripts/health-check.mjs` + `npm run test:health` (PASS & jalur gagal teruji).
- **Hardening LOW** — `validateThemeColors` (whitelist hex), token `--color-overlay-*`, rate limiting in-memory (auth 10/mnt, guestbook 20/mnt, publik 120/mnt) + header `X-RateLimit-*`, `assets/js/util.js` bersama, dokumentasi JWT dev secret.
- **2 bug diperbaiki & diverifikasi ulang** — `23502 not_null_violation` (default `isActive`/`sortOrder` gift account) & publik gift-accounts 401 (route publik sebelum `use(requireAuth)` + `requireAuth` per-route).

## Release Notes

## The Guest Experience Release — Tamu Dikelola, Amplop Digital Siap

### Undangan yang Lengkap Sampai ke Tamu

Setelah fitur inti (v1.2.0), Sprint 4 menutup siklus lengkap: pemilik mengelola siapa saja yang diundang, memantau konfirmasi kehadiran lewat statistik, dan memberi tamu cara memberi kado digital berupa info transfer. Di sisi tamu, halaman undangan kini menampilkan rekening amplop digital dengan satu ketukan untuk menyalin nomor rekening.

### Fondasi Kini Terverifikasi

Dengan PostgreSQL terpasang, seluruh API diuji end-to-end terhadap database asli — 21 langkah PASS, dari register sampai logout, termasuk guestbook, tamu, dan amplop digital. Dua bug nyata ditemukan selama proses (default kolom NOT NULL dan otorisasi route publik) dan langsung diperbaiki. Temuan audit Sprint 3 (AC7 + 5 LOW) seluruhnya tertutup.

### Keamanan Semakin Matang

Endpoint publik dan autentikasi kini dilindungi rate limiting in-memory dengan header `X-RateLimit-*`; warna tema divalidasi dengan whitelist hex; util render anti-XSS dipusatkan di satu file; dan dokumentasi secret development dipertegas. Siap melangkah ke Fase 3 (Launch).
