## Release Summary

Sprint 5 memberikan **kontrol administrasi** dan **keamanan akun** pada BERNADA.ID: dasbor admin (kelola pengguna & role, moderasi undangan & buku tamu) serta alur **lupa & reset password** dengan token acak sekali pakai (hash SHA-256, kedaluwarsa 24 jam) yang dikirim lewat email SMTP. Release ini adalah **The Admin & Account Security Release** — menyempurnakan Fase 2 dan menjadi jembatan menuju Fase 3 (Launch).

## Release Notes

## The Admin & Account Security Release — Admin Mengawal, Akun Semakin Aman

### Kontrol Penuh untuk Tim Platform

Admin kini memiliki dasbor terpisah: statistik platform, daftar pengguna dengan pencarian/filter/paginasi, detail jumlah aset tiap pengguna, pengelolaan role (dengan guard agar tidak mengubah role sendiri atau menurunkan admin terakhir), moderasi undangan (tarik dari publik), dan moderasi buku tamu (hapus entri). Akses admin diperiksa server per-request — bukan sekadar perlindungan tampilan.

### Akun Pengguna Kini Bisa Pulih Sendiri

Pengguna yang lupa password bisa meminta tautan reset via email (respons generik anti-enumerasi — tidak membocorkan apakah email terdaftar). Tautan memakai token acak sekali pakai yang disimpan sebagai hash SHA-256, kedaluwarsa 24 jam, dan seluruh sesi lama ikut dicabut saat password diganti. Di lingkungan pengembangan tanpa SMTP, tautan dicetak ke log server (`[mail:dev]`) agar alur tetap bisa diuji.

### Verifikasi Penuh, Dokumentasi Rapi

Seluruh fitur baru Sprint 5 diverifikasi end-to-end terhadap PostgreSQL asli — 25 langkah PASS, dari register sampai moderator admin — dan dicatat permanen. Pekerjaan yang sempat berjalan tanpa dokumen kini tersinkron: dokumen sprint, API, database, changelog, roadmap, dan konteks AI.
