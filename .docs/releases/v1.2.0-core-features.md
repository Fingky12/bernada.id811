## Release Summary

Sprint 3 menghadirkan **fitur inti platform** BERNADA.ID: pengguna dapat membuat akun, masuk, lalu membuat undangan digital sendiri — memilih template, menyesuaikan konten & tema, menyimpan, memublikasikan, dan mengelolanya — melalui API yang aman dan halaman builder di browser.

Release ini adalah **The Core Features Release** — jembatan dari fondasi (v1.1.0) menuju platform undangan digital yang benar-benar berfungsi.

---

## Highlights

- **Autentikasi lengkap** — register, login, logout, refresh (rotasi + revoke, cookie httpOnly, hash SHA-256), `GET /api/auth/me`, middleware `requireAuth`; password hash `bcryptjs`.
- **Template undangan** — `GET /api/templates` (publik, hanya aktif) + 6 template awal dari portofolio (migrasi `0002`).
- **Invitation API** — CRUD + publish/unpublish, owner-scoped, validasi server, parameter binding (`api/routes/invitations.js`).
- **Builder / editor undangan** — `pages/builder.html`: daftar undangan, editor (detail acara, pilih template, tema warna, galeri), pratinjau live, terbit/nonaktifkan/hapus, tautan `/u/:slug`.
- **Halaman publik `/u/:slug`** — cover "The Wedding Of", hitung mundur, tema warna dinamis, musik latar, lokasi (Google Maps + unduhan kalender `.ics`), galeri foto, kata sambutan.
- **RSVP & buku tamu** — tabel `guestbook` (migrasi `0003`) + endpoint publik list/create + formulir di halaman undangan + fallback demo lokal saat API/DB tidak aktif.
- **Galeri foto** — kolom `invitations.gallery` (JSONB), dikelola di builder, dirender di halaman publik.
- **Migrasi DB** — `0002` (refresh_tokens + seed template) & `0003` (gallery + guestbook).
- **Frontend modular** — `assets/js/api.js` (client API + auto-refresh, token di memori), `login.js`, `builder.js`, `invitation.js`, `demo-invitations.js`.

## Release Notes

## The Core Features Release — Platform Mulai Benar-Benar Hidup

### Dari Fondasi Menuju Fitur Inti

Setelah landing page yang mengesankan (v1.1.0), Sprint 3 membangun tiga lapis fitur inti: **autentikasi** (siapa penggunanya), **template** (pilihan desain), dan **builder undangan** (cara pengguna membuat undangan sendiri). Pengguna kini bisa daftar, masuk, membuat undangan, menyesuaikan tema, menerbitkan, lalu membagikan link ke tamu.

### API yang Aman dan Terstruktur

Backend memisahkan route (validasi), service (logika bisnis), dan query (parameter binding) — konsisten dengan prinsip clean architecture project. Autentikasi memakai JWT access short-lived + refresh token rotasi di cookie httpOnly yang hash di database: keseimbangan keamanan dan kenyamanan tanpa menyimpan token di `localStorage`.

### Halaman Publik yang Menyentuh

Tamu yang menerima link `/u/:slug` disambut cover pembuka, hitung mundur, tema warna khas pasangan, musik latar, lokasi (Google Maps + kalender), galeri foto, dan buku tamu untuk mengirim ucapan & konfirmasi kehadiran. Saat API/database belum tersedia, halaman tetap tampil melalui data demo bawaan — pengalaman tidak pernah benar-benar mati.

### Dibangun di Atas Fondasi Sprint 1 & 2

Seluruh CSS baru (pages, invitation) murni design token; komponen (button, card, badge, form) dipakai ulang; migrasi database bersifat append-only — kualitas fondasi tidak dikorbankan demi kecepatan fitur.
